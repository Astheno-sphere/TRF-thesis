## Requirements to rebuild

python3 with matplotlib, python-docx, pillow; the figure font ships in `figures_src/fonts` (Inter, SIL OFL, converted to TrueType); pandoc 3.1+; pdflatex and xelatex with elsarticle (`texlive-publishers`), psnfss (Times), TeX Gyre Termes and DejaVu fonts for the xelatex check; poppler-utils (pdftotext); soffice only for the QA docx-to-PDF check. Set `REVIEW_CODE` if the archive is not at `../review_code`. From the zip: unzip `review_code_anonymised.zip` next to `clsr_v0.9.1/` first (it unpacks to `review_code/`), then run `clsr_v0.9.1/build.sh`.

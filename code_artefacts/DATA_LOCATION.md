# Where the data lives

The eight untrimmed Synthea bundles this appendix describes are not duplicated
here. They exist in two places, both of which a reader can obtain:

- `repro_package/data/synthea_subset/` — the runnable reproduction package
- `data/synthea_subset/` in <https://github.com/Astheno-sphere/TRF> — the
  published artefact, which is what Appendix A's contents table refers to

They were held in a third copy under `repo_synthea_subset/` while the push to
GitHub was pending. That push completed on 28 September 2026, so the staging
copy was removed rather than left to drift. Provenance for the bundles is in
`repro_package/data/synthea_subset/README.md` and in
`Data_Provenance_Statement.md`.
